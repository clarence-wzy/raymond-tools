# 参与贡献

欢迎提交可复现的问题或范围明确的改进。

报告问题时请提供操作系统、Python / FFmpeg 版本、预期行为和实际行为。地址、请求头、目录和日志请脱敏；不要上传私人视频、缓存或凭据。

提交代码前：

1. 阅读[开发与测试说明](docs/DEVELOPMENT.md)。
2. 针对行为变化补充回归测试，使用本机服务和合成素材。
3. 运行 Python 测试、Node.js 测试及相关语法检查。
4. 同步更新使用说明和配置示例。

保持改动聚焦，遵循现有代码风格和目录结构。优先使用标准库；引入运行依赖前请说明必要性。涉及凭据、重定向、文件覆盖或缓存删除的改动，需要覆盖失败和取消路径。

提交贡献时，请确认你有权以主仓库的 [MIT License](../LICENSE) 提供相关代码；第三方代码应保留其适用的许可声明。
