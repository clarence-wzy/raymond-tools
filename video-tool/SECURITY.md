# 安全与隐私

## 本机服务

服务只监听 `127.0.0.1`，并检查 Host、Origin、请求类型和请求大小。它不提供远程认证或多用户隔离，不应通过反向代理、端口转发或修改监听地址向其他设备开放。

静态资源由显式白名单提供，不提供任意本机文件读取接口。下载目录由本机用户选择，下载输入仍应来自可信资源；本机服务不是运行未知媒体内容的沙箱。

## 请求头和凭据

原生 HLS 将自定义请求头限制在输入地址同源及明确配置的可信来源内，包含子清单、分片、密钥和重定向。协议、主机或端口不同即为不同来源。HTTPS 输入不会向 HTTP 资源发送这些请求头。

FFmpeg 兼容流程只接受 User-Agent、Accept、Accept-Language 自定义头；其他头会触发明确错误，避免通过 FFmpeg 的重定向或嵌套资源泄露凭据。详细规则见[配置说明](docs/CONFIGURATION.md#请求头与可信来源)。

请求头和原始任务 URL 在运行时保留在内存中，供重试和编辑使用；任务界面也会显示完整链接。这些信息不写入来源索引或分片记录。代理偏好保存在浏览器 localStorage，若代理地址有账号密码，也会在那里保留。

AES-128 密钥会保存在分片缓存内，以供本机 FFmpeg 合并和离线重试。不要共享整个缓存目录。

## 诊断信息

Python 引擎在日志和任务错误信息中隐藏 HTTP URL 路径、查询参数、URL 账号密码、敏感头和已知凭据值，包括 FFmpeg 原始错误输出。输出目录、文件名和主机名仍可能包含个人信息；第三方诊断文本也可能采用未覆盖的表示方式，分享前仍应人工检查。

历史 Bash 参考脚本不具备 Python 引擎的隐私保护，不应用于含私人签名或鉴权信息的地址。

不要把真实 Cookie、Token、签名链接、视频内容或本机配置提交到仓库。报告问题时使用脱敏信息和可复现的合成测试。如果怀疑凭据已经泄露，先撤销或轮换凭据。
