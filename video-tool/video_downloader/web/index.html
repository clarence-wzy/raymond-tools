Clash / TUN 使用说明
  • Clash 只开“系统代理”时，ffmpeg 不会自动使用；请选“指定 HTTP 代理”并填入 Clash 的 HTTP/mixed 端口。
  • Clash 开 TUN 时流量会在系统层被接管，应用内无法绕过；需要在 Clash 规则里按进程或域名分流。
  • m3u8 的主清单和分片会分别匹配规则，可在 Clash 的 Connections 面板确认每条连接走 DIRECT 还是代理。
  • “测试代理”只检查本机到代理端口的连通性，不验证代理出口和 Clash 规则。

下载原理 / 实际执行的命令

HLS 点播优先并发获取源分片，并保留下载缓存；ffmpeg 负责解密、合并，ffprobe 校验最终时长。不支持的 HLS 清单及普通视频使用兼容流程：

  1. ffprobe 读取总时长、起始时间和格式；
  2. 按时间片执行 ffmpeg -ss ... -c copy -f mpegts，每次产出一个分段；
  3. ffprobe 校验分段起止时间，必要时裁掉接缝重叠；
  4. 用 ffmpeg -f concat -c copy 把分段合并为最终文件。
ffmpeg -hide_banner -nostdin -y -xerror -rw_timeout 15000000 \
  -reconnect 1 -reconnect_streamed 1 \
  -seg_max_retry 10 -max_reload 100 \
  -stats_period 1 -progress pipe:1 -nostats \
  -copyts -ss 0.000 -i "视频地址" \
  -c copy -f mpegts "输出.mp4.parts/part_000.ts"

请求头、代理和 HLS 重试参数会按任务动态追加；日志里的 -headers 和 -http_proxy 值会隐藏。

迁移到另一台电脑时，复制整个 video-tools 目录，按 REMARK.md 安装 Python 与 ffmpeg 即可。
